UDF root-directory classifier source notice

src/storage/udf-disc-type.js adapts the read-only UDF layout and allocation
logic from DiscUtils.Udf 0.16.13, the dependency used by the reference server.
The installed NuGet package identifies this source revision:
https://github.com/DiscUtils/DiscUtils/tree/59d7cadab839c6d8dfcf52f8be5efe6d2ced190f/Library/DiscUtils.Udf

Relevant source files: UdfReader.cs, DescriptorTag.cs, PartitionDescriptor.cs,
LogicalVolumeDescriptor.cs, PartitionMap.cs, Type1PartitionMap.cs,
MetadataPartitionMap.cs, PhysicalPartition.cs, LogicalPartition.cs,
MetadataPartition.cs, FileSetDescriptor.cs, File.cs, FileEntry.cs,
ExtendedFileEntry.cs, FileContentBuffer.cs, InformationControlBlock.cs,
ShortAllocationDescriptor.cs, LongAllocationDescriptor.cs, Directory.cs,
FileIdentifier.cs and UdfUtilities.cs.

The JavaScript implementation exposes only DVD/Blu-ray root classification.
It does not mount, extract, write, or expose a general archive filesystem.
VFS reads, cancellation, version validation and bounded metadata buffers are
MediaManager integration code. Tests build isolated UDF descriptors and do
not contain third-party media or a copied filesystem image.
