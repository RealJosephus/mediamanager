Photo tag reader source attribution

src/metadata/photo-tags.js adapts image-tag behavior from TagLibSharp 2.3.0,
official mono/taglib-sharp commit b5ae84f2e84087bf160bb0471420200dd2b5d809.
The adapted JavaScript reads static JPEG, PNG, TIFF and CR2 metadata through
the caller's scoped storage assets. It does not embed the TagLibSharp runtime.
