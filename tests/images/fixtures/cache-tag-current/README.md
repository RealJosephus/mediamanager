# Current image cache tags

This component Oracle calls the same-run, source-bound Native `ImageProcessor` string, `BaseItem`, DTO, chapter and user overloads. Its configuration is controlled; file system, encoder and application path dependencies reject unexpected calls. It does not claim a Native HTTP host, filesystem timestamp discovery, image encoding or complete instance acceptance.

The inputs include the unmodified historical image HTTP item/image rows and the initial/updated user image rows, plus date and identity examples. The full supplied path and 100ns timestamp are retained. Dates include MinValue, MaxValue, a leap day and one, six and seven fractional digits. Paths include Windows drive case, slash direction, composed/decomposed Unicode and a separate item/image path. The item/DTO/chapter overloads use the item path; the user overload uses the profile image path. Missing chapter/user image values remain null.

It preserves the update-before-activity and delete-before-activity cache windows and unchanged `ImageInfos` assertions. `tests/images/http.test.js` replaces only the `ImageTag` value in the two named image-info expectations. Each value is bound to that item's exact original image row and a current Native overload result. All remaining HTTP fields, body bytes/hashes, headers, conditions, image dimensions, BlurHash and missing-image behavior retain the original comparisons. There is no recursive tag projection or new framework/error contract.
