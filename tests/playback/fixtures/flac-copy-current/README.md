Native MediaEncoder probes the original FLAC over controlled HTTP. StreamBuilder selects the route with the fixture's `NoEncodingSupport` test double. The progressive MP4 and fMP4 HLS builders execute FFmpeg packet copy, and DynamicHlsHelper obtains the manifest codec from that state. The apphost checks arguments for version queries, probes and explicit copy commands. Native's progressive command includes `-acodec copy -ar 44100`. Copy preserves the compressed packets. The comparison retains complete ffprobe streams, packets, payload hashes and rational timestamps for the input, Native output, an independent repeat and Node HTTP payloads including cold reads. Joining the HLS initialization and fragment bytes reconstructs the copied container for probing. Node's shared MediaEncoder receives the wrapper settings through the runtime's top-level `environment`. PlaybackInfo POSTs use an explicit PostgreSQL playback user with a real API key. Reports hash keys in playback URLs and retain original response lengths and digests.
