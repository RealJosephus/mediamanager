# MIME lookup inventory and image save extensions

The oracle invokes the designated native MimeTypes methods and reflects every compiled source-package and wrapper lookup entry. Its input inventory contains all 1180 package extensions, 25 native MIME overrides, 31 reverse overrides and 30 video extensions, producing 1202 distinct extensions and 963 distinct MIME values. It records 3706 filename/default/case/path observations and 4826 MIME/semicolon/case observations. Production uses only JavaScript and the resulting JSON lookup resource.

Filename lookup preserves native overrides, package mappings, video fallback extension case, explicit null/empty fallback values and dotfile/path behavior. Reverse lookup removes the first semicolon suffix without trimming and preserves the package's first matching extension choice. Known non-image MIME values remain valid inputs to the generic image save path, while HTTP image-upload validation uses its separate image-only contract.

`native.json` is the unchanged actual recording. Resource provenance additionally binds the original and captured native wrapper source, new designated assembly/build closure, source-only MimeTypes package archive/template/generated source, functional tables, license and notice. This is an actual lookup/resource oracle, not image decoding, HTTP execution or complete album refresh acceptance.
