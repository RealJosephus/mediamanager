# Source model binding regression inputs

`native-http-errors.json` contains the nine complete native HTTP responses that
differed in workflow run 39647768077 on Ubuntu. The original source report SHA-256,
artifact identity and designated native build identity are recorded. Request
bodies, status, content type, raw response text and parsed JSON are retained;
the fixture contains no credentials. The surrounding source-management test
ran the actual current native host, controllers, authentication and JSON/MVC
binding before its stopped SQLite transfer and production PostgreSQL sequence.

The targeted regression sends those exact bodies through a real PostgreSQL
runtime and official source routes using a real API key. It validates trace IDs
before mapping them and compares every other response member. It also proves
that rejected inputs do not modify configuration/current library rows or queue
a Guide operation. It does not replace the current full native source-management
HTTP differential, which continues to compare the same cases without relaxed
assertions. No local validation is performed when maintaining these fixtures.
