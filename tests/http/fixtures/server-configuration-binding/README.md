# Current server configuration MVC binding

This independent component runs the supplied `ConfigurationController` and
`ServerConfiguration` in the actual `AddJellyfinApi` MVC host, including JSON
converters, model validation, authorization and exception middleware. Each
request starts from a nonempty previous version. A controlled configuration
manager records the actual typed replacement argument and either stores it or
throws its original controlled I/O failure. Metadata options use the actual
controller's constructor defaults.

The Node comparison uses the formal configuration routes and authorization
service. It compares the complete HTTP response, every replacement field and
the complete live value, including signed 64-bit values and version setter
ordering. Request identity is validated before projection. Error types and
stacks are diagnostics; logger counts are not an acceptance condition.

Input bytes, current sealed source bindings, actual assembly bytes, oracle
sources, build/process receipts, raw responses and full comparisons are kept in
each new Actions output. No historical recording is regenerated or claimed.
Both HTTP hosts drain and close normally.

This component does not execute the production configuration manager's path
validation, XML persistence, events, PostgreSQL consumers or restart. Those
require their own current manager/runtime evidence. It starts no media executor.
