# Native JSON encoder boundary

Neutral UTF-16 code units drive the actual loaded JsonDefaults Default, PascalCase and CamelCase options. The typed DTO frame also contains array nulls, a dictionary with a null entry and Int64.MaxValue. Output records retain the exact serialized body, including BasicLatin/HTML escaping, plus signs and unpaired-surrogate replacement.

The driver opens only its neutral input and runs no server, repository or media I/O. Actual assemblies and selected clean JsonDefaults/JsonStringConverter sources are independently sealed. This boundary does not prove all DTO types, MVC negotiation, WebSocket transport or complete dirty-workspace build-input closure. Item DELETE uses its separate actual MVC recording.
