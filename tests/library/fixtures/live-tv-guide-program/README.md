# Guide program materialization

`Program.cs` invokes the selected native build's private `GuideManager.GetProgram` by reflection. Its actual `LiveTvDtoService` calls the actual `LibraryManager.GetNewItemId`; that library object has only its configuration dependency initialized because identity generation uses no repository. Actual `ProgramInfo`, `LiveTvProgram`, `ItemImageInfo`, provider-ID extensions, image methods and `BaseItem.OnMetadataChanged` execute. Library navigation and a fixed rating lookup are explicit controls. No database, guide orchestration, image downloader, stream or recording executor opens.

The fixture constructs native input dictionaries with the actual `ProgramInfo` constructor's ordinal-ignore-case comparer. Node receives each oracle's initialized `ProgramInfo` fields so the comparison isolates the materializer rather than inventing a second constructor or claiming JSON binding coverage. Existing Node items and channels come from the real branded native entity factory, including actual derived program getters. The Node metadata callback executes the existing `onMetadataChanged` with the same controlled rating result.

Cases cover new identity and tags, HD dimensions, series identifiers, episode/season numbers, premiere rules, exact 100ns duration differences, current schedule changes, provider-ID dictionary aliasing and Series writes, and changes that alter the live object without requesting a save. Ordinary matching ETags still consume fields; only the exact XMLTV prefix enables its fast return, including its early position before malformed incoming collections. Null genres and provider dictionaries preserve the actual partial mutation prefix. Images compare both resulting fields and the captured original object references, including in-place replacement, remote-URL short circuit, removal without a save flag and native reference distinctness.

For newly allocated programs, each side checks `DateCreated` and `DateModified` against its own actual invocation interval before replacing those values with comparison labels. Every other projected date compares native ticks. The result compares the complete consumed state and relevant derived flags, return flags, caller dictionary count, existing entity identity, copied genres, provider aliases and rating lookups. It does not establish repository serialization, DTOs, refresh query membership, transaction/rollback behavior, full guide refresh, phase acceptance or release acceptance.

Reports preserve source bindings, input/output SHA256, executing assembly hashes, native clock intervals and paired observations. Inputs contain only synthetic identifiers and fixture URLs. Run only through authorized Actions validation.

The same fixture invokes actual private `GetChannel` and its actual DTO identity method. A controlled library observes the real method's `CreateItem` versus `UpdateItemAsync(MetadataImport)` choices without persisting rows. Controlled `IFileSystem.GetFileInfo`/`GetLastWriteTimeUtc` return mapped synthetic metadata; no physical source path is opened. Node compares its materializer's returned choice with those actual native calls. Channel cases include unchanged and null tags, tag-array aliasing, tag/parent changes choosing create on the existing object, wrong-type identity replacement, ordinal field/image comparisons, retained missing images, local file-info failure prefixes, remote image reset versus local blurhash retention, and provider-ID trimming. Channel clocks are labeled only for actual allocation, independently of the native `isNew` create decision for an existing object.
