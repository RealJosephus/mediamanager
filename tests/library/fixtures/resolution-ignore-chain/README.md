# Native resolution ignore chain

These 21 cases execute the frozen LibraryManager.ResolvePaths with actual
CoreResolutionIgnoreRule, DotIgnoreIgnoreRule, MovieResolver, VideoListResolver
and ResolverHelper on real files. They record filtering before multi resolution,
empty/invalid/comment/negation/ancestor/nearest/BOM rules, mixed counts, hidden
files, hidden trailers, sample files, theme audio, stacks and ungrouped alternate filenames. All original resolved-item,
multi/single call, unchanged row/Data/link/file/cache/event projections remain.

The resolver list is limited to MovieResolver. Resolved entities are not saved;
the EF rows belong to the setup controls. Providers, collection membership,
media-source/external dispatch and the known ancestor namespace are controls.
Candidate media use Memory VFS only as a fixture backend; instance files and
both databases are real. No full scanner/MetadataService, network, concurrency,
migration or release acceptance is claimed.
