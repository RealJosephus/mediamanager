# Native Artist and Studio conflict inputs

`binding.json` selects two independently recorded real native runs for each
type. Set `MEDIAMANAGER_NATIVE_CONFLICT_INPUT_ROOT` to
`D:/mediamanager-validation/20261011/conflict-results-attempt3`.
Every repetition starts with a separate native discovery process. IDs used
for collision injection come from its actual GET and SQLite delta, with no
candidate identity algorithm. The main process then records blocked-directory,
normalized-name, same-path-name and wrong-type-ID requests, all 33 physical
SQLite tables at every stage, file bytes, shutdown processes and released ports.

The shared identity binding seals the designated dirty workspace build, SDK,
API-created source database and eleven exact preparation inputs. The separately
sealed audit, recorder snapshots, native LibraryManager source and actual
dotnet/Jellyfin/FFmpeg executables are verified before replay. Both recording
directories remain immutable; their complete directory digests are checked.

Candidate seeding uses only stopped pre-request BaseItems rows and the native
discovery identities. The production HTTP runtime uses real PostgreSQL and a
private state directory. Comparison retains the original count/presence/tree/
cleanup assertions, every HTTP response field, all 72 watched BaseItems columns,
all existing candidate rows and every observed relation table at each request.
Only individually bound server IDs and new directory creation/modification
clocks normalize. Candidate clocks must match the actual filesystem at 100 ns
precision; the blocked file must retain its recorded size and SHA-256.
Set `MEDIAMANAGER_CONFLICT_EVIDENCE` below the configured validation output root
to retain candidate captures, including captures from failing comparisons.

The candidate harness observes twelve tables and metadata path/type trees plus
the blocked file bytes, rather than all native physical tables or all state
file bytes. This evidence does not prove complete build/tool/OS influence
closure, complete scanning, Web clients, concurrency or release acceptance.
The historical missing-input consumers and failed prototype remain separate
historical evidence; no compatibility aliases or weakened oracles are added.
