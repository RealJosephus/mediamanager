# Video version discovery

The frozen LibraryManager runs actual ResolveAlternateVersion, ResolverHelper, GenericVideoResolver, UpdateItemAsync, stack discovery, cache eviction and DeleteItemsUnsafeFast over real EF SQLite and isolated files. Inputs explicitly select the resolver's concrete type and filename parsing policy; this is not a complete production resolver list.

The recording includes 23 cases, selected row columns, complete stored Data, exact Int64, batch order, events, parent cache/UserData invalidation, independent file/database deletion and real cancellation/SQL failures. Dynamic saved timestamps are range-checked within each native sample and then labeled `$UTC_SAVE`; the candidate must match its supplied clock and the stored column before normalization. State-root spelling is normalized, while IDs and relative paths remain exact. Collection membership, metadata saver, media-source collaborators and external-file dispatch are controls.

The candidate compares all 23 cases through ordinary single-file resolution and the repository batch boundary on real SQLite and PostgreSQL. Files use Memory VFS with a controlled creation time, plus real isolated instance-state directories and deletion. Additional regressions exercise the production default resolver and recursive update, preflight rejection before any write, internally deleted version-link baselines, cancellation rejection before attempted new-version insert SQL, and the probe/custom image persistence producers. GUID text is stored in native canonical form; projection uses the native Guid D formatter. Parent cache tests warm actual folder-cache entries and verify invalidation, and the operation's live item cache is evicted/reloaded for dropped versions. No complete scan/provider/network/user-deletion, arbitrary resolver types/disc formats, full scalar mapper or release acceptance is claimed.
