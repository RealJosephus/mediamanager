# Native music genre creation

`Program.cs` calls the designated build's actual `LibraryManager.GetMusicGenre`,
`CreateItem`, filesystem operations, EF-backed `ItemPersistenceService` and SQLite
repository. Fifteen isolated samples cover new and repeated lookups, existing
by-name entities, wrong-type replacement, warm video caches, Unicode and reserved
names, normalized identity options, a blocking file and save failure.

The raw recording retains all 72 mapped columns, pre-action constructor rows,
provider relations, directory timestamps, returned entities and ordered save/Added
observations. Application paths, virtual path projection, collection membership
and the injected save failure are controlled dependencies. No media or server
ports are opened. Initial rows are inputs to the PostgreSQL candidate tests;
result rows are comparison evidence only. Directory timestamps are compared with
each instance's actual filesystem before projecting isolated timestamps.

`provenance.json` binds the recording, recorder inputs, DLLs, execution and selected
designated source files. The full native build input closure is not established.
This recording does not prove scan scheduling, provider refresh, migration history,
native HTTP behavior or final release acceptance.
