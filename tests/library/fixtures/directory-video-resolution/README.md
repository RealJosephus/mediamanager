# Native directory video resolution

The recorder invokes the frozen `LibraryManager.ResolvePaths/ResolvePath`,
`MovieResolver`, `VideoListResolver`, `ResolverHelper` and `FolderResolver` with
Core/Dot ignore rules, a real nested filesystem and unchanged EF SQLite state.
The 34 scenes include ordinary file stacks, local versions, Folder fallback,
ignored members, extras, provider path attributes, inherited locks and creation
time configuration. The first 24 earlier native results are unchanged.

Every original resolved-item, dispatch, row, complete stored Data, relationship,
file, cache and event field participates in both database comparisons. Native
directory creation time and configured resolve time are checked against the
actual UTC recording window before being represented by `$UTC_RESOLVE`.
Candidate resolve time must equal its supplied clock before normalization.
Other file dates, nullable fields, IDs, Int64 values and relative paths remain
exact. The candidate media adapter and known empty ancestor namespace are
explicit fixture controls.

Only MovieResolver and FolderResolver are registered. The provider, collection,
media-source and external dispatch collaborators are controlled. Resolved items
are not saved; no recursive ValidateChildren, MetadataService, full resolver
list, disc layout, network fault, concurrent cache, migration or release
acceptance is established by this fixture. Separate actual CreateItems and
ValidateChildren recordings remain external evidence for subsequent work.
