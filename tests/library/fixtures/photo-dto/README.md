# Photo DTO properties and primary image aspect ratio

The native recording executes actual DtoService.SetPhotoProperties, JsonDefaults serialization, GetPrimaryImageAspectRatio and Photo.GetDefaultPrimaryImageAspectRatio. Repository parent lookup, image dimensions and logger are controlled. This is a helper/serializer observation, not complete native HTTP, SQL, static image decoding or Photo metadata-provider acceptance.

`input.json` contains `fields`, `dtoCases` and `aspectCases`. Each property case supplies Photo `values`, physical `parents` and optional `parentId`/`ownerId`; expected `wire` contains only selected fields after actual native serialization. Cases cover missing/empty/zero values, the nearest physical PhotoAlbum through ordinary folders, missing parents, owner-only references, album null/empty names and orientation null/known/unknown values.

Each aspect case supplies `kind`, Photo `width`/`height`/`orientation` and controlled `imageWidth`/`imageHeight`. Kinds are `none`, `remote`, `local`, `zero` and `error`. A missing primary image yields null; remote images use Photo's fallback; valid local dimensions take precedence; zero dimensions or decoder error fall back. Photo fallback swaps axes for LeftTop/LeftBottom/RightTop/RightBottom, accepts negative nonzero stored dimensions and delegates zero dimensions to BaseItem. The remote path intentionally starts with uppercase HTTP without being a valid URL, matching ItemImageInfo's prefix test.

`native.json` is the unchanged 219-observation output: 19 property cases with `{name,wire}` followed by 200 aspect cases with `{name,ratio,calls}`. The call count records the controlled dimensions seam. Provenance binds exact executed helper/project/props/input/output, the new designated build and closure manifest, relevant original and captured source files, and observed/serialization assemblies. ImageProcessor source additionally binds the cached positive-dimension branch required by the real callback; this production implementation is not executed by the native controlled dimensions seam. Reproduction takes output path then input path as oracle arguments.
