All 31 business-table digests and complete ItemValues rows are compared at each export/reimport boundary. This synthetic component fixture does not claim an actual Native server continuation or complete-instance exchange.

The helper binds source-offer files, the same-run build receipt, loaded Native assemblies and the platform's supplied SQLite library, then records Native output, SQL logs and individual candidate observations in the validation output directory. Native input files remain read-only; EF writes only its isolated output database. The controlled user-access seam supplies only TopParentId, so this is not complete policy, API, public-network, full-library, production-scale or release acceptance.
