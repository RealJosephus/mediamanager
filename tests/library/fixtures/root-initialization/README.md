# Native root initialization controls

`native.json` mechanically projects four frozen Jellyfin DLL controls: correct existing Playlists, missing Playlists, wrong parent, and both Aggregate/Playlists absent. Each includes the complete recorded before/ready state of 13 media/UserData tables and filesystem entries. `provenance.json` binds fixture bytes and source hashes; each scenario retains original artifact hashes, DLL digest, process exit, and released port. Existing evidence comes from `root-plugin-startup-native-v1/native-existing-minimal13`; three fresh controls come from `root-plugin-startup-native-v2`. Only before rows seed tests.

The regression calls actual `createRuntime` with legal isolated directories and no library-options override, and compares before the first public query. It checks all non-generated table fields, preserves correct existing rows and unrelated data, validates save timestamps and their order, and checks new plugin dates against real filesystem timestamps. Surrogate identity sequences are not captured in the native 13-table snapshot, so generated columns are explicitly excluded from candidate equality; raw original identities remain in the fixture. Directory relocation and dynamic clocks do not prove byte-for-byte equality with a historical host. Candidate HTTP authentication/transport and external native plugins are outside this regression.
