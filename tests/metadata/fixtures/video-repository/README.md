# Frozen video repository propagation oracle

The actual frozen Video.UpdateToRepositoryAsync and MetadataService.SaveItemAsync execute over typed entities. Parent/child repository commits, images, linked ID selection, cancellation and mutations are explicit controls. The recording proves copied and untouched fields, live reference sharing, order and failure boundaries, not native SQL, real NFO/image processing, media discovery or full library acceptance. Identities and the exact frozen sources/assemblies are sealed in provenance.json.
