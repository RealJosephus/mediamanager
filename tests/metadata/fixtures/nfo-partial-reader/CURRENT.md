# Current partial NFO reader comparison

`nfo-partial-reader.test.js` builds and executes `current/Oracle.csproj` against
the designated Native runtime from the same GitHub Actions run. All 41 original
neutral scenarios are retained in `current/input.json`. Each Native input file
is checked against its generated bytes, length and digest before its observation
is compared with the production Node parser and user-data import consumer.

The comparison covers success or failure, HasMetadata, item and provider values,
complete people and image prefixes, Episode merge behavior, BOM decoding and
malformed byte replacement. Ordered user lookup, data lookup and save calls keep
their reasons and value snapshots. Cancellation after the first save and a
failure on the second save retain their exact committed prefixes and current
versus persisted user-data values. The existing zero-ID provider consumer still
checks that transient reads do not save or replay user-data imports.

Public text is compared after well-formed JSON text conversion. Raw exception
and reader diagnostics remain in the Native recording. The scalar fixture owns
the broader field and layout matrix; provider discovery, real user-data database
transactions, emitted events and full filesystem race behavior remain separate
contracts.

`current-profile.json` records the current neutral input, every current oracle
source, project and shared build properties. The runner verifies the same-run
Native source and runtime closure, then retains scoped source bindings, build
and execution logs, consumed `scenarios.json`, all `.nfo` files, raw `native.json`
and `candidate-reader.json` under `nfo-partial-reader-current-*/`. Capture reports
claim component execution only, with phase and release acceptance false.

The original input, oracle, project, output, README, provenance, repeat record
and candidate-difference file remain unchanged historical evidence. Current
execution does not read them. The former archive-only `native-repeat.test.js`
is replaced by the actual current reader and scalar consumers.
