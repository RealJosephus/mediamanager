(U+0085 and U+FEFF) and a Windows-1252 XML declaration after 5000 spaces. They
prevent imposing ECMAScript whitespace or a fixed declaration probe limit on
native consumer values. Inputs and raw native execution are retained unchanged.
The same designated source build is independently bound by the main fixture.
